## 0. 一句话校准（2026-11-01 修订）

> **参考图不是"圆润卡通"，是"自然图鉴式的写实插画"。**

第一版做成了"圆头皮卡"，被当场指出。差别在三处，按重要性排序：

1. **叶子必须是一片片的**。一团"绿色的云"无论加多少层次都还是云。最小单位是橡树叶
   （有裂片、有叶柄、有明暗），见 `OAK_LEAF` + `Leaf`。
2. **整幅要降饱和**。原来的黄绿 / 亮蓝 / 粉红是"屏幕色"，参考图是"印刷色"：
   橄榄绿、赭石、燕麦、灰蓝。这一步在 `theme.ts` 里统一做了，比改形状更立竿见影。
3. **结构要真实**：树冠是"每根枝末挂一簇叶"，枝干从叶团之间露出来；
   兔子是**坐姿**（后腿折叠成一大块），不是"四条柱子撑一个椭圆"。

还有一条容易忽略的：**树冠往下长会盖住树干上的入口**（树洞、门）。
改完树冠一定要回头检查所有"贴在树干/墙上的可点物件"，必要时把它们挪到露出的那段。


> 这一轮把画风从"椭圆 + 描边"改成"层叠色块 + 真实骨相"。森林是样板间，
> 其余区域按同一套规则逐步替换。**改任何新物件之前先读这一页。**

参考图：`docs/style/style-E-flatreal.png`（AI 生成的方向图，只看风格，不直接用）。

## 0.1 第二轮校准（树、小精灵、光的方向）

第一轮把树的形状做对了，但**光的方向和画面不统一**：太阳在右上，树干的高光却画在左侧。
这一轮把三件事定死：

1. **单一光源在右上**。树干：左侧暗、右侧亮、中间留本色；叶簇：暗部往左下偏移、高光在右上；
   石头/蘑菇/鸟都照这个走。改这个比加细节管用得多。
2. **体积靠"明暗分界线"，不靠渐变**。三块平色、一条清楚的界线，这是读起来像圆柱的原因。
   用渐变反而糊。
3. **能用 fill 就别用粗 stroke 做体积**。粗 stroke 的端头会探出轮廓，在边缘糊出一条灰带
   （树干上真的出现过一条"贴上去的胶带"）。

造型上的三条经验：

- **轮廓必须是一条连续的线**。树干和它的板根如果是两个形状叠出来的，交界处会有横缝。
- **叶子的最小单位是一片叶子**：裂片 + 主脉 + 三对侧脉。一团"绿色的云"加多少层次都还是云。
- **每个物件问一句"它的识别特征是什么"**：蘑菇的菌褶、鸟的尾羽、蝴蝶的翅脉、
  石头的受光面。缺了那一样，孩子就得多看两眼。

动作上的一条：**点击反应必须是真实动物会做的**。转一整圈看着"有反应"，但转到一半是倒立的。

## 1. 三条硬规则

### 1.1 每个物体只用 2–3 个平色

不做渐变。

| 色阶 | 作用 | 例（夏·阔叶树） |
| --- | --- | --- |
| `dark` | 背光面 / 压在底下的那一层 | `#4c8443` |
| `leaf`（主色） | 物体本色 | `#77b866` |
| `light` | 受光面（左上） | `#a9dc90` |

**为什么不用渐变**：渐变缩到 60px 的精灵尺寸会糊成一片；三个色块到多小都还在。
这是 E 版和 A（水彩）/ D（厚涂）最根本的分歧点，也是它能在 SVG 里实现的原因。

### 1.2 光从左上来，而且只有一盏

- 亮面在左上，暗面在右下。
- 投影一律偏下（`translate(0, 3~4)` 或 `ellipse cy=0` 的浅色椭圆），不偏左。

### 1.3 形按真实结构走，不按"好画"走

| 错误画法 | 正确画法 |
| --- | --- |
| 树冠 = 几个椭圆叠在一起 | 叶簇 = 有起伏的闭合轮廓（`clumpPath`），边缘有叶尖 |
| 树干 = 等宽柱子 | 树干 = 底部宽、分叉处收细的锥形 + 露出的根 |
| 四足动物 = 椭圆身体 + 4 根矩形腿 | 背线拱、腹线收、后腿粗前腿细、头是侧脸骨相 |
| 花 = 5 个圆排一圈 | 花瓣是椭圆（有朝向），花枝上有一片叶 |
| 草 = 3 根从同一点伸出 | 5 根，长短不一，各自从地里长出 |

## 2. 复用件（都在 `src/v3/art.tsx`）

| 组件 | 用途 | 关键参数 |
| --- | --- | --- |
| `clumpPath(r, seed, squash)` | 一团叶子的轮廓（波浪边） | `seed` 固定，同物体每次渲染必须一样 |
| `<LeafClump x y r seed leaf dark light />` | 一簇叶子（三色） | 暗部自动往右下偏移 2.5/3.5 |
| `<LooseLeaf x y r rot fill dark />` | 一片散叶 | 只用在树冠最外缘，把圆边打碎 |
| `<Tree kind season night />` | 五种树（oak/pine/willow/birch/bare） | 季节换三色，夜里整体压暗偏蓝 |
| `<Bush />` / `<Tuft />` / `<FlowerProp />` / `<Ground />` | 灌木 / 草丛 / 花 / 地面 | 见各自注释 |

**树冠密度**：14 团叶簇 + 10 片散叶。少于这个数，树看起来"病了"。

## 3. 精灵模板（`src/v3/sprites.tsx`）

四足动物都由 `quad()` 生成，参数是颜色与部件（耳/尾/角/鬃毛）。

| 部位 | 做法 |
| --- | --- |
| 身体 | 一条闭合路径：臀最宽、肩略高、腹线内收。**不要用 ellipse** |
| 腹侧 | 只覆盖下半，不整圈包住（包住就成了"两色蛋"） |
| 背高光 | 一道细弧，`stroke` 用 belly 色，`opacity 0.5` |
| 腿 | 远侧两条压暗（`shade`），近侧后腿粗、前腿细；**都很短**，腿一长就成了小马 |
| 头 | 侧脸：前额圆、鼻梁下收。不要"圆 + 小圆"（那是雪人） |
| 尾巴 | 兔子是短圆尾，贴在臀后（不是身体左侧的一个球） |

新增四足动物：只传颜色/部件，**不要动骨架**。骨架一改，兔/狐/鹿/猫一起变。

## 4. 场景层

| 元素 | 规则 |
| --- | --- |
| 地面 | 远色 rect + 近色曲线 + 两层半透明色带（`rgba(58,88,52,0.07)` / `0.05`）叠出纵深 |
| 水面 | 三条长反光带 + 十几条碎波；只有碎波会像"蓝布上印了白线" |
| 沙滩 | 湿沙带（贴着水线）+ 两层沙面色带 + 断续的三层泡沫 |
| 岸边交界 | **不要画实线**。实线会读成"泳池池壁"（这个错犯过两次） |

## 6. 验收方式

改完 **必须截图看**，而且要看三种尺度：

1. 整屏（1440×810）——判断构图与色彩是否统一
2. 局部放大 2 倍（`.shots/e-rabbit.png` 这类）——判断骨架与三色是否成立
3. 缩到实际游戏尺寸（精灵约 50–70px）——判断细节有没有糊掉

`npm run shots` 会重拍 `docs/` 下的预览图；`scripts/_shot.mjs` 是临时的局部放大脚本（用完删）。

功能回归：`npm run test`、`test:regions`（美术改动不应影响命中区，但场景元素会参与命中测试）。
